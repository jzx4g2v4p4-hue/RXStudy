# RxStudy 💊

A simple, fast pharmacy flashcard app. Flashcards, Study Guides, and Audio — nothing else.

## How to use

Just open `index.html` in your browser. Everything saves automatically in your browser.

## Host on GitHub Pages (free)

1. Create a new GitHub repo (e.g. `rxstudy`)
2. Upload `index.html` to it
3. Go to **Settings → Pages → Source → main branch**
4. Your app is live at `https://yourusername.github.io/rxstudy`

## Import your content

Go to **⚙️ Manage → Import JSON** and select any `.json` file exported from this app or generated from your study guides.

## Keyboard shortcuts (Flashcards)

| Key | Action |
|-----|--------|
| Space / Enter | Flip card |
| ← | Previous card |
| → | Next card |
